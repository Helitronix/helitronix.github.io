# helitronix.github.io

Public web pages for Helitronix apps, served by GitHub Pages at https://helitronix.github.io/.

- `buggyblaster/index.html` (with `icon.png`, `screenshot.jpg`): Buggy Blaster's home page (Google's sign-in setup for
  Play Games links to it).
- `buggyblaster/privacy.html`: Buggy Blaster's privacy policy (the App Store and TestFlight link to it).
  Its source is `docs/privacy.html` in the private Buggy Blaster repo; copy it here after changing it.
